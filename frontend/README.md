# TERRA — Frontend

Aplicación web del sistema catastral urbano.

## Cómo correrlo

```bash
npm install
npm start
```

http://localhost:4200

## Rutas

| Ruta | Módulo |
|------|--------|
| `/app/unidades` | Unidades catastrales |
| `/app/unidades/:codigo` | Ficha del predio |
| `/app/mapa` | Consulta geográfica |
| `/app/tramites` | Trámites |
| `/app/recepcion` | Recepción / pre-registro |
| `/app/inspecciones` | Inspecciones |
| `/app/valoracion` | Valoración |
| `/app/catalogos` | Catálogos |
| `/app/salidas` | Certificados y fichas |
